# 操作與問題處理

## 啟動、更新與資料

- 執行 `VGHKS-bot.exe` 後，在本機瀏覽器登入院內帳號；各帳號的病歷、工作階段、設定及任務分開保存。
- 關閉瀏覽器不會停止 EXE 或已開始的任務。再次執行同一 EXE 可重開介面；完全退出請按「結束程式」。
- 更新前結束舊程式，只更換 EXE，保留完整 `VGHKS-bot-data/`。預設資料與 EXE 同層；`--data-dir` 指定的是整個管理目錄。
- 搬移／備份須攜帶整份資料目錄，包含資料庫、附件與憑證解密資訊。持有此目錄的人能使用其中憑證；私人資料不在發布包內。
- 登入頁及側欄「資料庫管理」可建立、開啟、備份、匯入獨立資料庫或切換資料庫。外部資料夾不會隨預設目錄一起移動。
- 唯讀開啟使用暫存副本，不改動來源；可檢閱、列印及匯出已存資料，不能登入、抓取或編輯。備份要繼續工作時先建立可編輯副本。
- 切換、複製或備份前，暫停任務並等目前讀取完成。目的資料夾須不存在；匯入不合併或覆寫原資料。

資料格式目前為 **1**，與 EXE 版本分開。不支援的格式會拒絕開啟，不自動轉換；來源檔案不因此刪除。

## 門診與病歷檢閱

1. 在「選擇病人清單」勾選病人，或在進階工具來源輸入病歷號／身分證號。多筆貼上會逐一核對；等待時保留原號碼，查核失敗或未完成前不能略過直接開始。
2. 選擇病歷檢閱條件並開始。SOAP 任務依所選範圍逐位處理；完成後點擊整個標題列可展開來源與條件，設定圖示仍是獨立操作。
3. 選取左欄病人閱讀 SOAP。病人清單連續捲動，按需從本機讀取摘要；捲動不會切換右側病人，也不會為全員預抓基本資料或檢查。
4. 基本資料、歷年數值、醫囑及掃描索引由各自按鈕啟動；優先顯示已存內容，未保存、不完整或快取需更新時才依原規則查詢。需重新核對時明確按更新。

### 清單、標題與 TAG

- 桌面病人清單依姓名、病歷號、序號與日期調整至 184–248px，把其餘空間留給 SOAP；窄畫面改為上下排列。
- 功能面板及病人清單皆使用邊線小三角箭頭收合，支援滑鼠、鍵盤與觸控。清單頂端的轉送、清除選取、勾選數與位置固定保留。
- 清單 TAG 最多兩行，其餘顯示「+N」；滑鼠移上可看完整提示，點擊可檢閱全部 TAG，不切換 SOAP 或改變選取。
- 姓名字級為 14px，清單其他資訊及 TAG 為 11px；無 TAG 不保留空白行。成功取得不重複標示，等待或有問題才顯示狀態。
- 視網膜比較、白內障分析及刀表更新沿用相同字級與小箭頭病人導覽，欄寬依內容限制在 184–248px，高度隨視窗調整，窄畫面改為上下排列。收合再展開保留清單位置及所選病人；刀表清單點選會定位到對應候選項目，保留尚未儲存的欄位。
- SOAP 內自動／手動 TAG 使用一致標題欄、標籤尺寸、間距與換行。自動 TAG 可定位到 SOAP 命中依據；手動 TAG 是病人標記。
- 點病歷號、身分證或電話 badge 只複製該欄。點姓名複製「病歷號、姓名、手機」三欄 Tab 分隔文字，可貼入試算表；沒有手機時第三欄留白。
- 未滿 55 歲使用紅色年齡 badge，55 歲以上及性別以一般文字顯示。剪貼簿遭瀏覽器拒絕時提供可選取文字。

「資料資訊」集中顯示時間。檢閱／索引核對是核對查詢條件與就診清單的時間；SOAP 取得是該份內容最後下載的時間，沿用快取不會改成這次檢閱時間。SOAP 標題保留醫師、案例號及保存／沿用狀態。

### SOAP、重試與備註

- SOAP 依 A+P、O、S 顯示，另保留診斷、藥囑、醫囑、其他及完整原文。來源只有 A+P 時不硬拆 A／P；缺值或解析問題明確標示。
- 慢性處方分開標示對應藥物與服藥期限。院方明示的月數／次數與依期限推估的週期分開呈現，不把估計當成院方月數。
- 內建自動 TAG 為手術 `# Arrange`、審查 `# APPLY`、追蹤 `# FU`；可設定全文或指定 SOAP 區塊。修改規則後可用本機 SOAP 重分類，不必重新抓取。
- 「tag 判定不完整」代表所需區塊未取得或無法解析，不能當成未命中。舊病歷若缺結構欄位，主動重新抓取該病人可補齊。
- 「重新抓取此病人」只更新這位病人的索引及 SOAP，沿用目前檢閱條件；更新全員須在設定明確選擇。普通續跑保留已成功內容。
- 備註依帳號、任務與病歷號保存，輸入後自動儲存。批次輸出涵蓋本次任務所有有備註病人，不受目前篩選限制；批次清除須確認。
- 可從爬蟲紀錄或「查詢歷次備註」重開舊任務。返回檢閱保留原病人及畫面；重新開啟程式會載入該帳號最近的檢閱。

### 基本資料與掛號

完整基本資料首次查閱時才另行取得，包含身分證、手機、住家電話、院方電話及聯絡人。成功保存後，切換病人、重開及離線檢閱使用本機內容；缺值不會觸發反覆查詢。

掛號紀錄分為今天及未來、過去與日期不明。缺少掛號狀態與未標示到診留白；只有院方明確標記才顯示未到診，空白不代表已就診。取消只顯示一次紅色標記，保留時間／人員。更新圖示位於關閉鈕旁；搜尋涵蓋可見欄位，底層原始資料仍保存。

## 報告、附件與比較

- 該次與歷年醫囑集中於同一張表，預設依醫囑名稱排序，同名檢查依開單時間由新到舊；歷年醫囑預設選取「眼科檢查」。點「醫囑名稱」、「開單時間」或「執行時間」表頭可切換排序方向，時間欄首次點擊為新到舊。保留名稱／日期搜尋及全部、眼科檢查、其他篩選，選取醫囑才取得報告。
- 歷年醫囑會自動補查超出歷史索引範圍的已核對門診，直接併入同一清單；更早的住院／急診醫囑受院方可查詢範圍限制。部分查詢失敗仍顯示已確認的醫囑，重試只補未完成項目。
- 同份報告圖片／PDF 仍逐一下載，每份驗證並保存後即可閱讀，不等整批完成；指定附件 GET 免額外間隔。索引、文字、登入、病人核對及院方限流／退避維持。
- 桌面左側為雙欄縮圖，右側顯示一份主檔案；窄畫面改為橫向附件列。後到附件不搶走目前選取、縮放或捲動位置，醫囑明細預設收合。
- 單份報告影像預設最適比例，點百分比可回到最適大小。檔案比較中的圖片可放大、縮小及重設為 100%；PDF 直接使用檢閱器內的比例調整，不顯示只改變外框大小的縮放按鈕。
- 「下載原檔」保存原始 PDF／圖片，文字可下載 TXT；「複製圖片」以 PNG 放入剪貼簿，也可使用瀏覽器右鍵操作。
- 同一病人最多加入六份附件比較。點「查看比較」才開啟工作區；旁邊 X 可確認清除整個比較佇列，附件不會刪除。切換病人或帳號會清空畫面選取。
- 關閉報告後，已開始的該份報告繼續背景取得。要停止請展開右下角進度卡按暫停，正在讀取的內容完成或逾時後停止下一份。
- 普通「重試未完成」重用成功分支，只補失敗、解析未完整或缺檔內容；「更新資料」是明確重新取得。

醫囑及掃描 PDF 可加入同一比較清單。歷年掃描先顯示索引，PDF 開啟或加入比較時才下載；類別、日期與就診可篩選，來源 subtype 不直接當成眼科分類。

### 本地 PACS 檢閱

JPG／PDF 報告維持主要檢視方式。醫囑清單每列提供「本地 PACS」，可直接交接所選醫囑，不必先開啟 JPG 報告。報告內、視網膜比較及白內障分析也保留「開啟本地 PACS」。

1. 本程式與院方 SmartIris／DownloadApp 必須在同一台 Windows 工作站執行，並已登入可查詢院內資料的帳號。預設檢查 `C:\TEDPCOCX\DownloadApp.exe` 與本機 `15516` 埠；請先自行啟動院方檢閱器。
2. 按下後才檢查本機服務、取得這筆醫囑的原生 PACS 入口並交接。舊快取若缺少入口資訊，只補查該筆醫囑；不重新下載已存 JPG。多份檢查會先顯示選單，選定後再按開啟。
3. 顯示「已交接本地 PACS」後，在院方檢閱器核對病人與影像；交接成功不代表影像已載入。檢閱器的視窗由院方程式管理。

沒有原生 PACS 入口的醫囑仍可看 JPG／PDF。未安裝、未啟動、權限無法確認或其他程式占用連接埠時會顯示原因；本平台不自動安裝或啟動檢閱器。逾時或連線中斷時先查看檢閱器，系統不自動重送。離線與唯讀資料庫僅供已存報告檢閱。

## 進階工具與刀表

| 工具 | 操作重點 |
| --- | --- |
| 病人轉送 | 單人或勾選批次加入工具，保留來源 SOAP；單純加入待處理不會啟動抓取 |
| 視網膜比較 | 檢閱 Va、眼底攝影、Microsonography、FAG 等數值／報告 |
| 白內障術前 | SOAP 與十五項眼科數值並列，醫囑附件可比較及匯出 |
| 刀表更新 | 先預覽逐格差異、核對來源與目的刀日，再套用；可信當日 SOAP 可設定排程 |
| 線上刀表管理 | 無須病人名單或院內登入，可管理月份／刀日、統計、水晶體清單及封存 |

白內障工具有自己的集合背景佇列，與按需病歷檢閱不同。首次開啟先處理目前病人，再依序處理其餘未完成項目；病人間保留 10–20 秒等待，可暫停／繼續或優先處理選定病人，成功資料不重抓。登出、離線及重啟後須按狀態續接，不因切頁擅自恢復已暫停佇列。

左上角以集合進度條顯示目前帳號「已保存人數／集合人數」與正在處理的病人，旁邊可暫停／繼續。部分待續跑的病人不計入已保存；右下角進度卡保留各任務的抓取階段與明細。

歷年醫囑索引若有無法核對的項目，白內障頁仍顯示已確認且屬於眼科就診的醫囑，並逐次補查已核對眼科就診。眼科範圍補查完成後即可顯示為已保存；原始索引的異常仍保留在 DEBUG，不會把未核對的醫囑當成有效資料。

白內障的單份醫囑圖片可直接放大、縮小，點百分比回到最適大小；各張圖片保留自己的比例與捲動位置。PDF 使用檢閱器內建的比例調整。

數值保留眼別、單位、原文及完整精度；不明眼別／矛盾值不猜測。驗光顯示 Sph、Cyl、Axis、SE，KM 顯示 K1、K2、Kavg 與 CYL；原始表格可核對。離線報告 ZIP 包含 HTML、SOAP、CSV／JSON、文字及已存附件，解壓完整內容後開啟；缺漏只標示，不自動補抓。

刀表連線見 [Google 設定](GOOGLE_SHEETS_SETUP.md)，同步、人工修改保留、永久 ID、斷線核對及封存見 [刀表規則](SHEET_SYNC.md)。主程式不執行日曆監控。

## 手術、審查與薪資

- **手術**：即時刀房是院內網頁，需內網及院方登入；醫師排程預設今天至兩個月後，可改醫師／日期。「今天及未來」與「過去」分區，日期已過不表示手術完成。重新查詢才抓取，失敗不覆蓋成功快照。
- **審查**：首次進入該帳號審查頁才啟動監控；先同步案件清單，新增或失敗案件才補醫囑。已結案內容更正仍保留版本；`F` 是上傳完成，不代表通過。
- **薪資**：另設薪資登入資訊，更新院方仍公布的期別；依原期別顯示醫療績點／專勤獎金，可匯出 CSV／JSON。院方撤下不刪除已存報表，金額及單位不混合加總。
- 審查／薪資監控可設 1 小時至 30 天，預設每日；只在 EXE 開啟、帳號在線及資料庫可編輯時執行。錯過多輪只補一次，關閉設定不取消已開始工作。

## 任務與本機資料管理

右下角集中顯示進度與比較入口，載入秒數獨立更新。進度可展開查看明細、暫停及前往紀錄；開啟模態視窗時位於其獨立底部區，避免蓋住報告內容。完成卡片自動收起，任務結果仍保存。

每帳號最多四個前景任務、64 個等待任務，院內操作依帳號序列執行；不同帳號各自隔離。畫面活動／閒置依既有輪詢更新，隱藏分頁停止畫面輪詢，EXE 工作仍持續。跨任務可共用同帳號、同病人與同條件的已核對讀取，取消單一訂閱不影響其他任務，也不提高爬蟲併發。

「病歷管理」提供 SOAP、病人檢查快取、門診掛號清單三類清除。先預覽範圍，再確認刪除；就診索引會連帶清除相依快取，附件僅在無其他引用時移除。集合、手動 TAG、備註及任務錯誤摘要保留；移除集合不等於刪病歷。切頁不會自動補回已清除內容，需主動更新。

## 問題處理與 DEBUG

| 狀況 | 處理方式 |
| --- | --- |
| 網路、DNS、TLS、Proxy 或登入失效 | 查看具體原因，恢復環境後重新連線，再續跑；輪詢不會反覆送密碼 |
| 密碼到期或要求變更 | 依院方入口處理後更新密碼；單純登入被拒不推測成鎖定或到期 |
| 病人／就診身分不符 | 停止該份取得，不保存可疑內容；從 DEBUG 查看核對證據 |
| 部分解析、附件缺檔 | 保留成功內容，明確續跑未完成；空結果須有院方證據，不能以錯誤冒充查無資料 |
| `TEXT_DECODE_INCOMPLETE` | 調整帳號文字編碼後重查，並匯出 DEBUG ZIP 的 charset／去識別解碼證據 |

在「爬蟲紀錄 → 對應任務 → DEBUG → 下載完整 DEBUG ZIP」匯出目前帳號的已存證據，離線與唯讀也可操作。ZIP 包含 `debug.json`、`sdk-context.json`、失敗來源與異常 SDK 時序；截斷、缺檔及驗證失敗會標示，舊版未保存的內容不能補回。

正常操作只保存摘要，異常、重試或 SDK 恢復才保存詳細資料。憑證值會遮罩，但失敗來源可能仍含醫療資料，匯出檔請留在私人環境。解碼診斷只保留固定公開替代字元標記及遮罩片段，不包含鄰近病人原始文字；技術判讀與容量規則見 [開發說明](DEVELOPMENT.md#debug-與問題定位)。
